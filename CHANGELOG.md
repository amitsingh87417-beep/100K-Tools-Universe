# Changelog

## v2.1.0 — 2026-11-02
- Expanded the catalogue to exactly 1,000 searchable tool configurations.
- Added new browser-side engines: palindrome, vowel count, anagram, Morse encode/decode, ROT13, hex encode/decode, UUID, Roman numerals, email/URL extraction, punctuation cleanup, prefix/suffix, unique-word count, text wrapping, CSV cleanup, JSON validation, XML escaping, HTML tag stripping, URL parsing, list shuffle/picker, NATO phonetic conversion and number-base conversion.
- Added Recent tools and local Result History.
- Added keyboard shortcuts for search and Escape navigation.
- Updated metadata and deployment documentation.
- Kept the white/blue responsive interface and Vite/Vercel setup.
